# Para Ale ♡

Una app web móvil con sobre interactivo, carta completa, melodía opcional y una sorpresa final. La carta está en `dist/app.js`; los colores y el diseño, en `dist/style.css`.

## Vista local

Con Node.js instalado, ejecuta `npm run dev` y abre http://localhost:4173.
Para verla desde el teléfono, conecta ambos dispositivos al mismo Wi-Fi y abre `http://IP-DEL-COMPUTADOR:4173`. El firewall de Windows debe permitir el acceso al servidor.

La versión de Sites se publica privada inicialmente. Para compartirla con Ale se debe configurar el acceso del sitio; el enlace privado por sí solo no le da acceso.

El manifiesto permite abrirla como una app desde la pantalla de inicio en navegadores compatibles. No es una aplicación nativa de Android o iOS. Las tipografías de Google Fonts requieren internet; hay tipografías de respaldo.
